## 3. วิธีใช้ไฟล์ในโฟลเดอร์นี้

* **ไฟล์ `.md`** คือข้อความต้นฉบับ (ภาษาไทย ปนศัพท์อังกฤษ) เปิดอ่านหรือ copy ได้เลย
* **ไฟล์ `.docx`** สร้างจาก `.md` ด้วย `python submission\build_docs.py` มีหัวข้อ ตาราง และรูปครบ ฟอนต์ **Sarabun**
  (Google Docs มีฟอนต์นี้)
  * **นำเข้า Google Docs:** Google Drive → New → File upload → เลือก `.docx` →
    คลิกขวา → Open with → Google Docs → File → **Save as Google Docs** → Share ให้เพื่อน
  * สารบัญ: ใน Google Docs ให้ Insert → Table of contents (สร้างจากหัวข้อให้อัตโนมัติ)
* **รูปประกอบ** อยู่ใน `figures/*.png` (สร้างจาก `figures/figures.py`) ลากลง Google Docs หรือ Canva ได้เลย
* **Brochure**: `2.2_Brochure/Brochure_example.pdf` เป็นตัวอย่างที่ทำเสร็จแล้ว ใช้ได้ 2 แบบ:
  เป็น **แผ่นพับ 3 ตอน** (A4 แนวนอน, พิมพ์สองหน้าแบบพลิกด้านสั้น แล้วพับ)
  1. ใช้ตัวนี้เลย (พิมพ์ได้ทันที) หรือ
  2. ทำใหม่ใน Canva (A4 แนวนอน 2 หน้า แบ่ง 3 ช่อง ขนาดช่องดูใน `brochure_text.md`) โดยใช้ข้อความใน `brochure_text.md` และรูปใน `figures/`
     (Canva เปิด PDF ให้แก้ได้ด้วย: Create design → Import file → เลือก PDF แต่ฟอนต์ไทยอาจเพี้ยน)
* **ส่วนที่ต้องเติมเอง** ทำเครื่องหมายไว้เป็น `[...]` (ชื่อ, รหัส, ลิงก์, รูปถ่ายจริง) ค้นหาด้วย Ctrl+F คำว่า `[`

1. **วิดีโอต้องเป็น Public** (ไม่ใช่ Unlisted) และชื่อต้องตรง `CE_KMITL_Digital_2569_xxxx`

   * ปกติแค่ "claim" (มีโฆษณา) แต่บางเพลงอาจถูก **block** ทั้งคลิป
   * อัปโหลดให้เร็วแล้วดูสถานะใน YouTube Studio
   * ถ้าโดน block: ลดเสียงเกมช่วงนั้นหรือตัดให้สั้นลง แล้วใช้เพลงจาก YouTube Audio Library เป็นพื้นหลัง
3. **หน้าเพื่อนในเกม** (ลูกบอลเด้ง BOUNCERS): ถ้าจะให้เห็นในวิดีโอสาธารณะ ต้องขออนุญาตเพื่อนก่อน หรือเลือกช็อตที่ไม่เห็นชัด
4. **ชื่อ + รหัส นศ. ทุกคน** ต้องอยู่ในวิดีโอ (และใส่ในเอกสารทุกฉบับด้วย)

6. ถ้าจะ push โฟลเดอร์นี้ขึ้น GitHub ให้คิดก่อนว่าอยากให้ชื่อและรหัสนักศึกษาเป็นสาธารณะหรือไม่
