# ข้อความ Brochure สำหรับ Canva (แผ่นพับ 3 ตอน)

ตัวอย่างที่ทำเสร็จแล้ว: `Brochure_example.pdf` (2 หน้า: ด้านนอก + ด้านใน) ดูเป็นรูป: `Brochure_outside.png`, `Brochure_inside.png`
ใช้แบบนี้ได้เลย หรือจะทำใหม่ใน Canva ก็ได้ โดย copy ข้อความจากช่องด้านล่าง

## รูปแบบ: A4 แนวนอน พับ 3 ตอน (roll fold / tri-fold)

```
 ด้านนอก (หน้า 1)                         ด้านใน (หน้า 2)
┌─────────┬──────────┬──────────┐      ┌──────────┬──────────┬─────────┐
│ P2      │ P6       │ P1       │      │ P3       │ P4       │ P5      │
│ ฝาพับใน │ ปกหลัง    │ ปกหน้า   │      │ เล่นยังไง │ CHAOS    │ ภาพ+เสียง│
│ 97 mm   │ 100 mm   │ 100 mm   │      │ 100 mm   │ 100 mm   │ 97 mm   │
└─────────┴──────────┴──────────┘      └──────────┴──────────┴─────────┘
```

* **ลำดับที่คนอ่านเห็น:** ปกหน้า P1 → เปิดปก เห็น P3 คู่กับ P2 → เปิดฝาพับ เห็นด้านในทั้งแผ่น P3 P4 P5 → ปกหลัง P6
* **ฝาพับ (P2 / P5) แคบกว่า 3 mm** เพื่อให้พับเก็บเข้าไปข้างในได้ไม่ติดสัน เส้นพับอยู่ที่ 97 / 197 mm (ด้านนอก) และ 100 / 200 mm (ด้านใน)
* **ใน Canva:** สร้าง A4 แนวนอน (29.7 × 21 cm) 2 หน้า หรือเลือก template "Trifold Brochure" (ของ Canva เป็น Letter ให้เปลี่ยนขนาดเป็น A4) เปิด Rulers and guides แล้ววางเส้นนำที่ตำแหน่งพับ เว้นขอบในแต่ละช่องประมาณ 8 mm
* **พิมพ์:** สองหน้า (duplex) แนวนอน เลือก **"พลิกด้านสั้น" (flip on short edge)** แล้วพิมพ์ทดลอง 1 แผ่นก่อน พับฝา P5 เข้าก่อน แล้วพับปก P1 ทับ มีขีดเล็กๆ ที่ขอบบน/ล่างบอกตำแหน่งพับ

**ฟอนต์ที่ใช้ในตัวอย่าง** (มีใน Canva ทั้งหมด): หัวข้อ **Kanit** (หนา), เนื้อความ **Sarabun**, โลโก้ **Press Start 2P**
**สี:** พื้น `#11163A` (น้ำเงินเข้ม), สีบล็อกเตตริส I `#22D3EE` O `#FACC15` T `#A855F7` S `#22C55E` Z `#EF4444` J `#3B82F6` L `#F97316`, ชมพูสื่อ `#F472B6`
**รูป:** `figures/screenshot_versus.png`, `screenshot_chaos_flip.png` (ปก), `screenshot_chaos_task.png` (P4), `screenshot_win.png` (P5)
แนะนำให้ **เปลี่ยนเป็นรูปถ่ายจริง** ของบอร์ดสองบอร์ดกับจอขณะเล่น (ดูน่าเชื่อกว่าภาพจากการจำลอง)
**พิมพ์:** พื้นเข้มเต็มหน้าใช้หมึกเยอะ และเครื่องพิมพ์ทั่วไปจะมีขอบขาว ถ้าอยากประหยัดหมึก ให้กลับเป็นพื้นขาวแล้วใช้สีบล็อกเป็นสีเน้น

เกณฑ์คะแนน: **สวยงาม, เข้าใจง่าย, น่าสนใจ** → ข้อความสั้น รูปใหญ่ เลขเด่น

## P2 ฝาพับ ด้านนอก (ด้านนอก ซ้าย: เห็นทันทีที่เปิดปก)

**หัวเล็ก**
> TETRIS DUEL คืออะไร

**หัวข้อ**
> เตตริส 2 คน บน 2 บอร์ด FPGA **แต่มีของแถมเพียบ**

**คำโปรย**
> ต่อบอร์ดสองบอร์ดด้วยสาย 3 เส้น แล้วแข่งกันล้างแถว ระหว่างเล่นต้องทำภารกิจด้วยสวิตช์ ทำสำเร็จก็ได้ป่วนจอเพื่อน

**จุดขาย 3 กล่อง** (เลขใหญ่ซ้าย ข้อความขวา)

| ตัวเลขใหญ่ | หัวข้อ | รายละเอียด |
|---|---|---|
| 2 × 2 | 2 ผู้เล่น 2 บอร์ด | ขึ้น LINKED ใน 0.5 วินาที เริ่มพร้อมกัน ตัดสินผลตรงกัน |
| 11 | การโจมตีสุดป่วน | กลับจอ สลับซ้ายขวา บล็อกล่องหน ลูกบอลบังจอ ล็อกปุ่ม และวิดีโอ 3 เรื่อง |
| 6.9 MB | วิดีโอ + เพลงในตัว | เพลงประกอบ คลิปชนะ/แพ้ ตัวละครลอย เก็บในแฟลชบนบอร์ด |

**กล่องเน้นด้านล่าง**
> **ไม่มี CPU สักตัว**: เกม ภาพ เสียง การเชื่อมบอร์ด และเครื่องเล่นวิดีโอ คือวงจรดิจิทัลใน FPGA ล้วนๆ เขียนด้วย VHDL

## P3 เล่นยังไง (ด้านใน ซ้าย)

**หัวข้อ**: ขั้นที่ 1 · เล่นยังไง (3 การ์ด มีเลขใหญ่)
1. **ต่อสาย 3 เส้น**: TX ↔ RX และ GND ระหว่างสองบอร์ด จอขึ้น LINKED
2. **กดเริ่มที่ไหนก็ได้**: ทั้งสองจอเริ่มพร้อมกัน แถบ RIVAL บอกความสูงกองของเพื่อน
3. **ล้างแถว ส่งขยะ**: ล้าง 2 / 3 / 4 แถว ส่ง 1 / 2 / 4 แถวไปดันจอเพื่อน คนรอดคนสุดท้ายชนะ

**ปุ่มควบคุม** (รูปปุ่มกากบาท 5 ปุ่ม + ป้ายด้านขวา)
* SW16 หมุน · SW14 / SW20 ซ้าย-ขวา · SW18 ตกทันที / เริ่มเกม · SW23 ตกช้า
* แถวสวิตช์ 8 ตัว: สวิตช์ 8 ตัวซ้าย = ภารกิจ เช่น 229 = 1110 0101

**บรรทัดล่าง**
> สวิตช์ฝั่งขวา: SW6 เปิด CHAOS · SW4 เพลง · SW5 เสียงเอฟเฟกต์ · SW2 หยุดเกม

> ▼ สำเร็จ
> **5/8 โจมตีจอเพื่อน · 3/8 โบนัส** (FREEZE หยุดแรงโน้มถ่วง · SINK ลดกอง 2 แถว · I-PIECE)

**ป้ายการโจมตี 11 แบบ** (ขอบแดง, 3 อันท้ายขอบชมพู): MIRROR · FLIP · BLIND · BOUNCERS · +3 GARBAGE · CURSED · SPEED · LOCK · Bad Apple!! · OIIA OIIA · JEVIL

## P5 ภาพ + เสียงจากแฟลชบนบอร์ด (ด้านใน ขวา: ฝาพับ)

**หัวข้อ**: ขั้นที่ 3 · ภาพ + เสียง จากแฟลชบนบอร์ด

**4 กล่อง (สีชมพู)**
* **♪ เพลงตอนเล่น**: 2 เพลงสลับกัน โดนโจมตีจบแล้วเล่นต่อจุดเดิม

* **★ ชนะ / แพ้**: คลิปฉลอง หรือ... rickroll และ jump scare
* **◎ ตัวละครลอย**: Jevil ลอยทั่วจอ หน้าเพื่อนบนลูกบอลเด้ง
